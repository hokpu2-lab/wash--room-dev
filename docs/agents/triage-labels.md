# Triage Labels

| Label | Meaning |
|---|---|
| `needs-triage` | The request has not yet been assessed. |
| `needs-info` | More information is required from a human. |
| `ready-for-agent` | The work is sufficiently specified for an agent to implement. |
| `ready-for-human` | The work requires human review or action. |
| `wontfix` | The request will not be implemented. |
