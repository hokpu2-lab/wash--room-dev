# Domain Documentation

This is a single-context repository for the laundry-management system.

Before implementation:

1. Read `/CONTEXT.md`.
2. Read `/docs/requirements.md`.
3. Read relevant decisions under `/docs/adr/`.
4. Preserve the established laundry-order, batch, procedure-stage, equipment, cart, institution, and site terminology.
5. If a requested change conflicts with an accepted ADR, identify the conflict before implementation.
